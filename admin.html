Как включить запись в Таблицу:
  1. Открой Таблицу → Расширения → Apps Script
  2. Вставь код из файла APPS_SCRIPT.gs (в папке сайта)
  3. Деплой → Развернуть как веб-приложение → Доступ: Anyone → Копируй URL
  4. Вставь URL в db.js → APPS_SCRIPT_URL
  5. Дай таблице доступ "Читатель для всех у кого есть ссылка" (Файл → Настройки доступа)
Без Apps Script регистрация работает в кеше (localStorage) и чтение из Таблицы — но новые записи не попадут в Таблицу пока не задеплоишь скрипт.
